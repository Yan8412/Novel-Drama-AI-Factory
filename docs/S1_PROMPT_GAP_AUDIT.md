# Redacted prompt-gap audit

This public document contains reusable findings from a local read-only audit. Production prompt text, story details, asset identifiers, media, hashes, billing records and source paths are excluded. Exact line-level evidence and hashes are retained in a separate local private evidence record outside this repository.

The local audit inspected the installed optimizer and three directors, accepted compiler/contact rules, provider execution boundaries, frozen source/effective text, and original QA records. It did not rerun generation or independently repeat full video QA. Observed-output classifications below rely on the preserved QA evidence, not a new model judgement.

## Narrow changes justified by the audit

- Add candidate evidence/provenance and mode-specific capability/cost checks without changing accepted dispatch or cost authority.
- Add offline lifecycle/contact completeness cases without replacing the accepted structured contact model.
- Keep the optimizer as the orchestration entry; preserve domain ownership and existing intent schemas in isolated candidate overlays.
- Review source/effective fidelity explicitly. Preserve original bytes and distinguish reviewed newline transformations from semantic changes.

`PRESENT_BUT_OUTPUT_FAILED` does not identify a unique cause. Input conflicts, observation limits and stochastic generation behavior remain alternative explanations. No frozen production prompt, reference, QA result, or accepted runtime was changed by this audit. No improved video result is claimed.
