# Future experiment design (not execution authorization)

This branch supports offline comparison design only. Historical outputs can be
quality references; their consumed submission authority is never reusable.

Proposed arms, subject to independent approval:

- An unchanged endpoint-mode baseline using approved inputs.
- A revised endpoint-mode candidate derived from structured facts and measured gaps.
- Another mode only if fresh provider evidence explicitly supports every required
  input role and no endpoint or identity contract is weakened.

Freeze evaluation criteria before execution: object persistence and explained
exits, visible assistance and load transfer, natural motion, identity/cardinality,
endpoint compatibility, seam continuity, and verified settled cost. Compare inputs
and mode changes separately so results do not imply a unique cause without evidence.

A later authorization must name the provider/model, reviewed exact inputs,
per-call and total spend ceilings with units, independent submission allocation,
zero automatic retries, validity window, and the unchanged QA contract. Every arm
needs fresh technical and cost checks through existing production gates. Unknown
state stops resubmission; a failed QA result does not grant another attempt.

No numerical budget, provider quote, generation count allocation, or approval is
issued by this proposal. No experiment is performed in this PR.
