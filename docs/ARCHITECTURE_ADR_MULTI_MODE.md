# ADR: advisory mode routing beside the accepted compiler

Status: candidate only, not installed and not production admission.

## Integration seam

Preserve the accepted pipeline: Canon and ShotIntent -> cinematic, performance,
and spatial Director proposals -> structured motion/contact inputs -> existing
Compiler -> Provider adapter -> existing authorization and admission gates.
This candidate supplies additional review findings between structured planning
and provider-specific preparation. It neither replaces typed contact checks nor
modifies the authoritative GenerationRecipe.

1. Inspect existing source/effective/request text before proposing more wording.
2. Classify each constraint as PRESENT, MISSING, CONTRADICTORY, AMBIGUOUS,
   PRESENT_BUT_OUTPUT_FAILED, or UNVERIFIED. Existing text plus an uncertain output
   is PRESENT with output UNVERIFIED, not an invented missing rule.
3. Feed confirmed facts, continuous timing and explicit observation requirements
   to the candidate text compiler. Provenance labels are caller assertions, not
   proof of real-world truth.
4. Feed the router model-specific current capability, exact endpoint requirements,
   permitted modes, character/contact risk and comparable cost evidence.
5. Return CANDIDATE_ONLY, HUMAN_REVIEW or BLOCKED; never grant production admission.

## Modes and boundaries

| Mode | Required evidence | Constraint |
|---|---|---|
| Text-to-video | Explicit text-only mode | Cannot silently discard required anchors |
| Image-to-video | Explicit first-frame support | Cannot discard a mandatory final frame |
| First/last frames | Explicit first and last support | Endpoints do not prove intermediate contact |
| Multiple keyframes | Explicit intermediate-frame support and verified inputs | Generic video support is insufficient |
| Motion reference | Explicit motion-reference and required endpoint support | Reference existence does not prove output physics |

Missing, future-dated, expired, unmatched, unsupported, or unvalidated evidence
must not yield an admitted action. Multiple actors, transfers of load, and critical
object lifecycle remain review risks even when the provider exposes controls.
Budget screening of a fresh quote is not a guarantee of settled cost. Production
cost controls, human authorization, retries, and final video QA remain external.
Frozen or already submitted work cannot be rerouted by this module.

## Cross-platform boundary

The candidate uses Python standard-library data objects and paths. It does not
inherit operating-system credential stores, shell commands, CUDA or MPS behavior
from production. Windows verification and real macOS runtime verification are
separate acceptance claims. See the acceptance matrix.
